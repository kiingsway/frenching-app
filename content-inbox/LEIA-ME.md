# Caixa de entrada de conteúdo

Coloque aqui os arquivos `.json` das páginas de estudo (feitos por outra IA, no formato de
[docs/pedidos-para-outras-ias.md](../docs/pedidos-para-outras-ias.md)). Depois, em qualquer sessão
do Claude, diga: **"adicionar o próximo conteúdo"**.

O Claude pega o arquivo mais antigo, importa, revisa, gera os áudios e move o JSON para `feitos/`.
Os arquivos desta pasta não vão para o Git.
